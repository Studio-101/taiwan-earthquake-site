# 台灣地震 3D 互動圖：專案規則

用中央氣象署地震目錄（1990–2025）做一個網頁版 3D 互動圖，向一般大眾（以 45 歲以上台灣觀眾為主）解釋台灣地底的板塊結構。核心效果是把地表「掀開」，讓觀眾看見地震點排列出隱沒板塊的形狀。

## 絕對規則（每次工作都要遵守）

1. 地震資料只能來自 `data/` 裡的中央氣象署 XML 檔。不可以生成、補齊、模擬或「示範用」地任何地震資料。資料讀不到或格式不對，就停下來告訴我。
2. 畫面上的每個數字、狀態、標籤都必須來自真實資料或可說明的計算。不放裝飾性的假數據（例如假的「系統正常」、假的即時數值）。
3. 不使用中央氣象署或任何機構的 Logo，只用文字標示資料來源。
4. 不要自行解釋資料中意義不明的欄位（例如 Quality、ReviewStatus），原樣保留。
5. 座標換算、比例、誇大倍率都寫成獨立函式並加註解說明公式；任何誇大比例都要顯示在畫面上。
6. 需要外部資料（海岸線、地形等）時，先告訴我建議的來源與授權，由我下載放進 `data/`，不要自行從網路抓取。
7. 介面全部使用繁體中文，字體要大，深色背景。

## 工作方式

- 一次只執行一個階段，階段說明在 `docs/phases/`。每個階段做完要停下來回報，等我確認後才進行下一階段。
- 寫程式前先讀 `docs/data-notes.md`，裡面有資料結構與已知的特殊狀況。
- 每個階段完成後，用 `verify-data` 技能產生驗證報告。
- 不要修改 `data/` 裡的原始 XML 檔。產生的檔案放在：轉換腳本 `scripts/`、整理後的資料 `data/earthquakes.csv`、網頁 `web/`。
