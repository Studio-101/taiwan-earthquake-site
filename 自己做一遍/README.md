# 自己做一遍

用 AI 從原始地震資料開始，一步步做出台灣地震 3D 互動圖。

我用的工具是 Antigravity。`AGENTS.md` 是給 AI 看的專案規則，`.agents/skills/` 是 Antigravity 的技能格式，用其他 AI 工具可能不會自動讀取。

## 開始前

1. 在 GitHub 頁面按 **Code → Download ZIP**，下載後解壓縮。
2. 用 AI 工具開啟 **`自己做一遍`** 這個資料夾。不要開整個專案，否則 AI 會看到完成品。

## 怎麼做

對 AI 說：

1. 「請執行 docs/phases/phase-1-資料轉換.md」
2. AI 停下來回報後，打開驗證報告，對照 `docs/data-notes.md` 的參考數值。
3. 沒問題就說：「確認，請執行 docs/phases/phase-2-點雲畫面.md」
4. 第三、四階段也一樣，一次做一個階段，確認後才往下。

## 資料夾內容

| 檔案 | 用途 |
| --- | --- |
| `AGENTS.md` | 專案規則，每次工作都要遵守 |
| `docs/phases/` | 四個階段的任務 |
| `docs/data-notes.md` | 資料結構、特殊狀況與參考數值 |
| `.agents/skills/verify-data/` | 驗證報告的檢查清單 |
| `data/` | 中央氣象署原始地震目錄，不要讓 AI 修改 |

## 要記得的事

- AI 說「全部通過」不等於真的通過，參考數值和集集地震那筆要親自核對。
- 第二、三階段需要自己下載海岸線和地形資料，AI 會先告訴你來源。真的找不到，可以用我的檔案：海岸線在最外層的 `data/`，地形在 `製作紀錄/外部資料/`。
- 同樣的提示詞，每次做出來的結果都可能不同，你的版本不會和我的一模一樣。
