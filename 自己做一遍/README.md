# 自己做一遍

用 AI 從原始地震資料開始，一步步做出台灣地震 3D 互動圖。不會寫程式也沒關係，程式由 AI 來寫，你負責下指令和檢查結果。

我用的工具是 Antigravity，下面都以它為例。如果你用其他 AI 工具，步驟大致相同，但 `.agents/skills/` 裡的驗證技能可能不會自動讀取。

## 第一步：把資料放進 Antigravity

資料不需要「搬進去」。Antigravity 就像檔案總管，你只要把檔案下載到電腦，再用它打開那個資料夾就好。

### 1. 下載

1. 打開[專案首頁](https://github.com/Studio-101/taiwan-earthquake-site)。
2. 按綠色的 **Code** 按鈕，再按 **Download ZIP**。
3. 電腦會下載一個叫 `taiwan-earthquake-site-main.zip` 的檔案，通常在「下載」資料夾。

### 2. 解壓縮

- **Windows：** 在 ZIP 檔上按滑鼠右鍵，選「解壓縮全部」，再按「解壓縮」。
- **Mac：** 直接點兩下 ZIP 檔。

解壓縮後，一直點進資料夾，直到看見 `自己做一遍` 這個資料夾。Windows 可能要多點一層同名的資料夾，這是正常的。

建議把 `自己做一遍` 整個資料夾拖到桌面，之後比較好找。

### 3. 用 Antigravity 打開

1. 打開 Antigravity。
2. 在上方選單按 **File**，再按 **Open Folder**。
3. 選 `自己做一遍` 這個資料夾，按確定。
4. 如果跳出視窗問你是否信任這個資料夾，選信任。

### 4. 確認有沒有開對

看 Antigravity 左邊的檔案清單，應該要看到 `AGENTS.md`、`data`、`docs`。

如果你看到的是 `index.html` 或 `製作紀錄`，代表開到外面一層了，AI 會看到完成品。請重新開啟，選裡面的 `自己做一遍`。

## 真的搞不定？直接請 AI 幫你

卡在上面任何一步都不用緊張。把 ZIP 下載好之後，打開 Antigravity 的對話框，複製下面這段話貼給它：

```text
我下載了一個檔案 taiwan-earthquake-site-main.zip，應該在「下載」資料夾。
請幫我解壓縮，把裡面的「自己做一遍」資料夾放到桌面。
接著幫我用 Antigravity 開啟這個資料夾。如果你沒辦法直接開，就一步一步告訴我要按哪裡。
我想自己從頭做一遍，所以請不要讀取其他資料夾的內容。
```

AI 如果問你能不能存取檔案，可以同意。任何看不懂的畫面，也可以截圖貼給 AI，問它「這是什麼意思？我下一步要按哪裡？」

## 第二步：開始做

在 Antigravity 的對話框輸入：

```text
請執行 docs/phases/phase-1-資料轉換.md
```

接下來照這個順序：

1. AI 做完會停下來回報。打開它產生的驗證報告，和 `docs/data-notes.md` 裡的參考數值對照。
2. 沒問題的話，輸入：「確認，請執行 docs/phases/phase-2-點雲畫面.md」
3. 第三、四階段也一樣，一次做一個階段，確認後才往下。

如果 AI 說電腦缺少某個軟體（例如 Python），請它教你安裝，或請它用電腦裡已有的工具完成。

## 資料夾內容

| 檔案 | 用途 |
| --- | --- |
| `AGENTS.md` | 專案規則，每次工作都要遵守 |
| `docs/phases/` | 四個階段的任務 |
| `docs/data-notes.md` | 資料結構、特殊狀況與參考數值 |
| `.agents/skills/verify-data/` | 驗證報告的檢查清單 |
| `data/` | 中央氣象署原始地震目錄，不要讓 AI 修改 |

## 要記得的事

- AI 說「全部通過」不等於真的通過，參考數值和集集地震那筆要親自核對。
- 第二、三階段需要自己下載海岸線和地形資料，AI 會先告訴你來源。真的找不到，可以用我的檔案：海岸線在最外層的 `data/`，地形在 `製作紀錄/外部資料/`。
- 同樣的提示詞，每次做出來的結果都可能不同，你的版本不會和我的一模一樣。
