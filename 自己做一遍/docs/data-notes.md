# 資料說明

寫任何讀取或轉換程式之前，先讀這份文件。

## 資料來源

- 中央氣象署地震目錄，1990–2025 年，每年一個 XML 檔：`data/CWA-EQ-Catalog-YYYY.xml`
- 每個檔案都已由官方篩選為**規模 3.0 以上**（`file.csv` 的描述：「YYYY年規模3以上地震目錄」）
- 授權：政府資料開放授權第 1 版
- 畫面上的來源標示文字：「資料來源：交通部中央氣象署地震目錄（1990–2025），政府資料開放授權」
- `file.csv`、`manifest.csv`、`schema-file.csv` 只是檔案清單與說明，不是地震資料，也不是欄位定義

## XML 結構

- 命名空間：`urn:cwa:gov:tw:cwacommon:0.1`（解析時必須帶上，否則找不到節點）
- 檔案資訊在 `<CatalogInfo>`：`MagnitudeRange`、`StartTime`、`EndTime`、`Region`（`LongitudeRange`、`LatitudeRange`）、`DepthRange`、`RecordNumber`
- 每筆地震是一個 `<EarthquakeInfo>` 節點

| 欄位 | 意義 | 備註 |
| --- | --- | --- |
| `OriginTime` | 發震時間 | ISO 8601，含 `+08:00` 時區 |
| `EpicenterLongitude` | 震央經度 | 度 |
| `EpicenterLatitude` | 震央緯度 | 度 |
| `FocalDepth` | 震源深度 | 公里 |
| `LocalMagnitude` | 芮氏規模 | 數值前可能有空白，需 trim |
| `Quality` | A～D | 意義未在檔案中說明，原樣保留，不要自行解釋 |
| `ReviewStatus` | F、X | 意義未在檔案中說明，原樣保留，不要自行解釋 |
| 其他 | `StationNumber`、`PhaseNumber`、`MinimumEpicenterDistance`、`gap`、`rms`、`erh`、`erz` | 轉換時可保留，第一版畫面不使用 |

## 已知的特殊狀況（重要）

1. **各年份的涵蓋範圍不同。**多數年份是經度 118–124、緯度 20–27；但 1996、1997、1999、2003、2012 年只有經度 119–123、緯度 21–26。所有年份的**共同範圍是經度 119–123、緯度 21–26**。網頁若要疊加多個年份，應只畫共同範圍內的點，否則早期年份的邊緣會看起來「沒有地震」。CSV 仍保留全部資料。
2. **少數資料超出該檔自己標示的範圍**（每年 0～5 筆，例如經度 126.434）。保留在 CSV，回報筆數即可。
3. **早期資料品質較差。**Quality 為 C 或 D 的比例在 1990 年代約 78～91%，2009 年後降到約 56～67%，2024–2025 年為 49%。沒有明顯的斷點，是逐年改善。
4. **大地震後的餘震會讓筆數暴增**：1999 年（集集地震）5,959 筆、2024 年 4,834 筆，是全部年份中最多的兩年。
