# 第二階段：3D 點雲畫面

目標：在網頁上把每筆地震畫成 3D 空間中的一個點，讓觀眾從側面看見往地底斜插的地震帶。這個階段不做地形、掀開效果或動畫。

## 開始前

- 確認 `data/earthquakes.csv` 存在（第一階段的產出）。
- 需要台灣海岸線資料。先告訴我建議的來源、格式與授權（例如 Natural Earth 的海岸線），由我下載放進 `data/`。拿到之前先不要畫海岸線。

## 要做的事

1. 在 `web/` 建立單頁網頁，使用 Three.js，只讀取 `data/earthquakes.csv` 與我提供的海岸線檔。
2. 預設只畫共同範圍（經度 119–123、緯度 21–26）內的地震，並在畫面上標出這個範圍的邊框；設一個開關可以顯示全部資料。
3. 座標換算寫成獨立函式並註解公式：
   - 經緯度轉成以公里為單位的平面座標（說明使用的投影方式與中心點）
   - 深度往下，水平與垂直都是 1:1 真實比例
4. 點的樣式：
   - 顏色依深度分級，附圖例（標示各級的深度範圍，單位公里）
   - 大小依規模，附圖例
   - 約 7 萬個點，使用 `THREE.Points` 一次繪製
5. 海岸線畫在深度 0 的平面上。
6. 滑鼠可旋轉、縮放、平移；提供「俯視」「從東側看」「從南側看」三個視角按鈕。
7. 畫面角落顯示：資料來源文字、目前顯示的點數、時間範圍。
