# 第三階段：地形與「掀開地表」

目標：加上台灣陸地與海底地形，用滑桿把地表掀開或變透明，露出底下的地震點。

## 開始前（先跟我確認，不要直接動手）

- 需要的地形資料：台灣陸地數值地形模型、周邊海底地形（例如 GEBCO）。先告訴我建議的來源、解析度、檔案大小與授權，由我下載放進 `data/`。
- 提出地形的垂直誇大建議：玉山不到 4 公里，在約 400 公里寬的畫面上幾乎看不出起伏。誇大只套用在地形，不可以套用在地震深度。
- 提出「掀開」的呈現方式（例如：地表透明度滑桿、地表往上抬升、切開一個剖面），各附優缺點，等我選。

## 我確認後要做的事

1. 依選定方式實作地形與掀開滑桿。
2. 畫面上顯示地形的垂直誇大倍率（例如「地形高度放大 5 倍，地震深度為真實比例」）。
3. 畫面上加註地形資料的來源與授權。
