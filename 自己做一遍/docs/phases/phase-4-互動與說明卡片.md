# 第四階段：互動篩選與白話說明卡片

目標：讓觀眾自己操作時間與規模，並用白話卡片解釋看到的現象。

## 要做的事

1. 年份滑桿（1990–2025），可播放「逐年累積」動畫。
2. 規模篩選（例如 3、4、5、6 以上）。
3. Quality 篩選：可只顯示特定等級。說明文字只寫「依資料中的 Quality 欄位篩選」，不要解釋 A～D 的意義。
4. 點擊單一地震，顯示它在原始資料中的時間、經度、緯度、深度、規模。
5. 白話說明卡片：
   - 我會提供每張卡片的內容與出處，你只負責排版和顯示
   - 不要自己撰寫地球科學的說明內容；如果需要範例文字來排版，用「（待填入）」佔位
   - 每張卡片底部顯示出處
